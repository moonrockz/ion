## [0.1.0] - 2026-09-28

### Added

- Add the Ion core data model and text encoding
- Add Ion binary descriptors and Ion Schema loading and validation
- Add the ion CLI with print and validate
- Add visitor and fold traversal APIs
- Add the Ion text tokenizer (CST token stream)
- Add the Ion event stream and push handler (SAX API)
- Add the Ion concrete syntax tree (CST)
- Interoperate with moonbitlang/x decimals for arithmetic
- Write S-expression operators bare in Ion text
- Resolve Ion text symbol-ID literals
- Add Ion Hash (Ion Hash 1.0, SHA-256)
- **schema:** Load and validate the Cookbook's logical-relationships page
- Add the Ion binary codec and an async streaming layer (#3)
- **json:** Convert between Ion values and JSON (#4)
- **text:** Read Ion text from asynchronous byte sources
- **text:** Write Ion text to asynchronous byte sinks
- **text:** Apply version markers and local symbol tables
- **cli:** Stream Ion input instead of reading it whole

### Changed

- Resolve system symbol IDs in the data model

### Documentation

- Document the four parsing APIs
- Note the golden fixtures in the test workflow
- List the known gaps in the roadmap
- Add a README with checked examples to every package

### Fixed

- **schema:** Model `contains` as value containment per ISL
- **text:** Round-trip non-BMP characters and symbol-ID-looking symbols
- **text:** Quote S-expression operators that contain a comment start
- **binary:** End a decimal or timestamp at its own length
- Conform to the Ion 1.0 test suite
- **schema:** Accept range:: for length constraints
- **cli:** Read piped stdin in fromjson and validate

### Performance

- **text:** Parse a streamed value once, not once per chunk
- **stream:** Read in large chunks and stop copying per value
